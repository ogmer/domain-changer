## 開発手順

1.`npm run build`でdistにフォルダを再生成
2.distフォルダをchrome上で読み込み問題なければzip化して審査に送る

## インストール

1. `chrome://extensions/` を開く
2. デベロッパーモードを有効にする
3. `dist` フォルダを読み込む

## 使い方

1. 拡張のアイコンをクリックしてポップアップを開く
2. 置換元ドメインと置換先ドメインを入力
3. ブックマークを読み込む
4. プレビューで確認してから置換実行

**注意**: 操作は元に戻せないので、事前にブックマークをバックアップしてください。
